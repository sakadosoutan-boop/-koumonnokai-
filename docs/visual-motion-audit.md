# 2026-11-03 ビジュアルと動作の再点検

本編と同じ人物・背景を使い、全9舞台をブラウザーで確認した。宴席では登場・剣舞・翼蔽・飲酒・食事を途中で止め、全景・寄り・上方を照合した。新しい[場面の点検画面](../tools/visual-audit.html)では、舞台、照明、注目人物、斜めからの視点、経過時間を切り替えられる。

## 発見して修正した問題

| 場面 | 問題 | 修正 |
|---|---|---|
| 樊噲の登場 | 閉じた帷から盾が突き抜ける | 開始位置を外側へ移し、帷が先に開くタイミングへ変更。歩幅に合わせて腰を下げ、到着位置と立位の高さを維持 |
| 登場の追従カメラ | 踏み出した靴が下端に切れる | 追従距離に余裕を追加 |
| 生彘肩 | 顔への寄りで床の肉・盾が切れる | 口元から床の盾までを含む構図。縦長と本文パネルを考慮し、手前の劉邦に遮られない通路側から撮る |
| 軍門・垓下 | 柵の横木が門の開口を横断する | 横木を門の左右に分割 |
| 脱出 | 騎乗に座位を流用し、脚が消えて見える | 専用の騎乗姿勢で脚を馬体の外へ出し、両手を手綱へ接触させる |
| 脱出 | 馬の上下動と乗り手がずれる | 同一フレームの鞍の高さに追従 |
| 脱出 | 盾を自由な腕と同じように振り回す | 盾を肩の近くで立てて保持し、柄と握りの接触を維持 |
| 脱出 | 走行の足が浮き、地面を滑る | 接地区間と足の振り戻しを分け、移動速度に合わせて接地点を固定 |
| 地面・馬 | 舞台の起伏と脚の高さが合わない | 演技する範囲と脱出路を平坦化し、静止した馬の4蹄を床へ合わせる |
| 馬 | たてがみの先端が上を向き、前髪が浮く | 房の根元を実際の馬体表面へ合わせ、先を下へ向ける |
| 脱出の衣服・視界 | 座位の裾が馬具を貫通し、手前の樹冠が画面を遮る | 鞍の左右へ垂れる専用の裾を作り、手前の樹木をカメラの後方へ配置 |
| 長時間の脱出表示 | 周回の瞬間に人物とカメラが1フレームずれる | 移動距離を人物配置より先に折り返す |

## 回帰検査

- 帷の全三角形と実際の盾の包囲箱を、登場の181段階で照合。
- 登場の靴の接地・関節の連続性を高／低画質で確認。
- 食事は横長／縦長、本文パネルの有無、5段階で実メッシュの画面内への収まりと、他の人物に遮られないことを確認。
- 門の開口と脱出路の地面を、実際の形状へのレイで確認。
- 騎乗は41段階で、実際の手の握り、手綱、手首、脚、鞍の追従を確認。
- 走行は241段階で足の到達・接地・滑りを確認。盾の姿勢と握りも別途61段階で照合。
- 人物の形状検査を15人 × 14姿勢 × 2画質の420条件へ拡張（登場・騎乗を追加）。
- `npm test`、宴席の密な動作検査、配布用HTMLのビルド、CIのブラウザー検査を併用する。

顔・髪・髭・衣装の元アセットと頭部の圧縮データは変更していない。前回の軽量化を維持し、今回の修正は姿勢・接触・構図・舞台形状が中心。

これは全端末・全フレームの目視確認を意味しない。布の完全な物理衝突、走る馬の蹄の接地点固定、簡略化した船・樹木の造形には引き続き改善の余地がある。
