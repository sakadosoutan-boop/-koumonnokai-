- 「吾所以有天下者何」：返り点がなかったので「吾所‐以㆔有㆓天下㆒者何」と付けました。
- 二点・三点・下点に対応する点が後ろにあるかを確かめるテストを加えました。

- **読み込みの軽量化**：頭部データ（約16MB、圧縮後約7.4MB）と手のデータの読み込みでページの表示が止まっていたため、表紙を出してから裏で読み込むようにしました（`src/js/koumon-asset-loader.js`）。人物を作る前に読み込みを待ち、待つ間は「人物のデータを読み込んでいます…（影絵ならすぐ遊べる）」と表示します。影絵（2D）を選んでいる端末では読み込みません。8Mbps 相当に絞った回線で、表紙が出るまで約1.8秒、3D の人物の準備まで約31秒。読み込み後の人物は頭部データで作られることを確認しました。配布用の一枚HTMLにはデータを埋め込み、オフラインでも動きます。
