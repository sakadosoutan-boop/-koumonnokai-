# プリント演習の使い方

表紙の「05 プリント演習」、または物語中の「目次 → プリント演習を選ぶ」から開く。授業中は必要な活動だけを指定してよい。物語の続き・命・席次ゲームの途中配置には影響しない。

| 活動 | プリントの対応箇所（PDF内ページ） | 操作 | 直リンクの末尾 |
|---|---|---|---|
| 所属と行動をつなぐ | 2・6・7・12 | 陣営と働きかける相手を選ぶ | `#activity-relationships` |
| 剣舞の危機を組み立てる | 5〜6 | 出来事の札を上下へ動かす | `#activity-sword-order` |
| 省略された人物を補う | 5・7・12 | 行為者・対象・命令者を選ぶ | `#activity-omitted-people` |
| 樊噲の弁論を整理する | 10〜11 | 発言の論証上の役割を分類 | `#activity-argument` |
| 樊噲はどこに立つ？ | 7〜8 | 項王に対する位置と顔の向きを選ぶ | `#activity-formation` |
| 本文と人物像を分ける | 4・6・12 | 本文の記述と解釈を分類し、人物比較を記述 | `#activity-evidence` |

一覧は `#activities`。目次の「授業で場面を指定する」から、各活動のURLをコピーできる。配布用の一枚HTML（`dist/index.html`）にも同じ活動が含まれる。

回答は操作のたびに、その端末・ブラウザーへ保存する。「本文と照らす」で根拠と説明を確かめ、回答を変更して再挑戦できる。「札を戻す」は現在の回答を戻すが、初回・最高の結果と自由記述は保つ。端末や配信元を変えたときに自動同期はしない。

表紙の「学習記録」には初回・最高の正答数、確認回数、自由記述が入る。コピーまたはテキスト保存で提出できる。氏名や回答を外部サービスへ自動送信する機能はない。

## 教材上の扱い

- 添付の授業プリント・教科書・指導書を照合し、設問と説明を独自に作成した。添付PDF・解答紙面・地図画像そのものは配信しない。引用は『史記』本文の短句。
- 項伯の所属と援助先、曹無傷の所属と密告先を分ける。人物の所属だけで行動を決めつけない。
- 樊噲の弁論は「樊噲がそう説明した内容」として整理する。関所守備などの動機を中立な確定事実として扱わない。
- 立ち位置図は項王を基準とした模式図。本文が確定しない細かな侵入経路は採点しない。
- 人物像は複数の読みを認める。分類で判定するのは本文に書かれているかどうかで、自由記述の意見は自動採点しない。
- 諸説のある「与之同命」の指示対象や、婚姻の約束と義兄弟の混同は新規設問の正解に用いない。

## 検証

`tests/activities.test.cjs` は全活動の採点、未回答、再挑戦、重複採点、不正な保存値、記述のエスケープ、保存復元、物語の状態保全、直リンク、学習記録を検査する。実画面では一覧・選択・並べ替え・位置図・記述と縦長表示を確認する。
