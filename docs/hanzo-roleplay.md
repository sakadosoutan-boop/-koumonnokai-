# 范増として考える AIロールプレイの手引き

『史記』「鴻門之会」の本文を根拠に、生徒が范増となってAIの項王へ進言する活動です。目標は、相手が懸念を聞き、対応策を再検討できるように話すことです。殺害の決断や歴史の改変を成功条件にしません。

## 場面と資料

活動は、范増が玉玦を三度挙げても項王が応じなかった直後、**項荘の剣舞が始まる前**に置きます。追加の対話そのものは創作です。剣舞・樊噲の乱入・沛公の退出はまだ起きていません。

アプリの表紙、鴻門の会の結末、終章から「范増として考える」を開けます。使う原文を選んで指示文をコピーすると、段番号・原文・書き下し文が末尾に付きます。AIにはこの資料だけから引用させます。指示文の正本は `src/data/koumon.js` の `AI_PROMPT` です。本文を伴わない指示文だけの配布は避け、アプリから毎回コピーしてください。

ワークシートは [hanzo-roleplay.docx](worksheets/hanzo-roleplay.docx)（A4横・表裏）です。本文をまだ読んでいないクラスでは、先に導入「鴻門への道」と原文帳を用いて、両陣営の関係を確認します。

## 進め方 50分

1. **準備 15分**：表面Ⅰ・Ⅱ。原文帳から短い引用と段番号を記録し、「本文に書かれた行動」「人物の主張」「自分の解釈」を区別します。
2. **対話 15分**：資料付き指示文をAIへ貼り、五回まで進言します。表面Ⅲに、自分の主張・相手の返答・使った段番号を記録します。
3. **講評を確かめる 5分**：数値採点は行いません。裏面ⅰでAIの講評を原文と照合し、引用や説明が正しいか確認します。
4. **振り返り 15分**：裏面ⅱ〜ⅳ。根拠と主張のつながり、反論に応じた修正、本文とAIの違いを説明します。アプリの振り返り欄にも記録・保存・テキスト出力できます。

## 根拠を検討する視点

| 資料 | 本文で確認できること | 問い返したいこと |
| --- | --- | --- |
| 曹無傷の密告 g01 | 曹無傷が沛公の野心を項羽へ報告した | 報告された内容を、そのまま真実と見なせるか |
| 范増の進言 g02 | 范増は財物・婦女への態度の変化を指摘し、人に気を望ませたと語る | 「天子の気」は范増の主張・解釈である。何が観察で、何が推論か |
| 項伯の進言 g08 | 功績のある人を攻めるのは不義だという進言に、項王は許諾した | 項王の返答からどこまで価値観を推測できるか |
| 沛公の謝罪 g09 | 沛公は共に秦と戦ったことを述べ、項王は密告者の名を明かした | 両者の関係や語り方は判断にどう関わるか |
| 座次と玉玦 g10 | 范増は三度玉玦を示し、項王は黙然として応じない | 沈黙の理由は一つに決められるか |

本文で記された言動、そこからの解釈、AIが作った台詞を分けて扱います。AIの反応は、史実の人物の心理を証明するものではありません。

## 活動後に照合すること

本文では、沛公の退出後に項王はすでに陳平へ呼び戻しを命じています（g15）。したがって「陳平を呼びに行かせた」ことを、范増の説得成功の証拠にはできません。この段は活動中の人物が知る未来ではなく、活動後に読む比較資料です。

終章の高祖の評「項羽は一の范増有れども用ゐる能はず」も、後の勝者による評価として読みます。玉玦への沈黙を説明する唯一の正解にはしません。樊噲の発言や剣舞など、後続の場面との比較も対話後に行います。

## 評価の観点

| 観点 | 確認する学習の姿 |
| --- | --- |
| 知識・技能 | 段番号を添えて正確に引用し、語句・句法を踏まえて意味を説明できる |
| 思考・判断・表現 | 根拠から主張への筋道を示し、相手の反論に応じて提案を修正できる |
| 学習への取り組み | AIの出力を本文と照合し、解釈や引用を修正できる |

AIの講評は成績評価そのものにはせず、教員が本文の根拠と生徒の説明を確認します。アプリ内でAIへ直接送信はしません。生徒の利用環境は学校の方針に合わせ、個人情報を指示文に加えない運用としてください。
