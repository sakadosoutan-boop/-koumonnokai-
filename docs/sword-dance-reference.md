# 剣舞の参考映像と動作設計

参考はユーザー指定の[ORICON「キングダム実写特別動画、山本千尋の剣舞」](https://www.youtube.com/watch?v=csDw9aJC2xA)です。43秒・24fpsの公開映像を取得し、全体を1秒間隔、主要部分を0.5秒間隔で確認しました。以下は実フレームからの観察です。

| 時間 | 観察した動き | 宴席へ取り入れる要素 |
| --- | --- | --- |
| 14〜18秒 | 水平へ長く伸びた剣と高い空き手、続いて頭上の弧と胴の前傾 | 伸びのある構え、腕の対向、上段からの流れ |
| 20〜25秒 | 腰を傾けて剣を下げ、横へ払い、体の前で回収する | 低い払いと腰の返し、剣先の連続した弧 |
| 25.5〜29秒 | 片膝を上げて剣を肩近くへ寄せ、方向を変え、上段から低く斬る | 短い構え直し、踏み替えから斬り下ろしへの接続 |
| 30〜33秒 | 低い剣を回収し、空き手を伸ばして横へ開く | 斬った後の余勢と次の構えへの流れ |
| 34〜40秒 | 移動・踏み替え・短い跳躍を経て深い低姿勢へ収束 | 足の切り替え、重心の上下、低い踏み込み |

映像の遠景では足元の細部が小さく、7〜13秒から接地方法は判定していません。接地中の靴の向きや膝の曲げ方は、ゲームの実モデルで別途検査します。

ゲームでは、伸ばす・巻く・払う・構え直すという基本的な動きと緩急を参考にします。広い屋外での跳躍と大きな移動は、宴席の位置関係に合わせて踏み込みと斜めの方向転換に置き換えます。項荘の剣舞と、沛公をかばう項伯の受けを描き分けます。動きは授業用の創作演出です。

前版では、剣を立てた構えを長く保ったまま全身を一回転させ、足の接地点だけを固定していました。今回は剣・腰・肩・足の連動を評価し、接地中の靴の向きと足裏の位置も確認します。動画自体と解析用フレームは確認用のローカルデータとして扱い、ゲームには独自の動作コードを使用します。
