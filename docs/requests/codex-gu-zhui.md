# 依頼：虞美人の顔と、騅（項王の駿馬）・馬全般の見た目を作り直す

## 背景
- 史記「鴻門之会」の授業用ゲーム（このリポジトリ、公開は GitHub Pages）。第二部「垓下・烏江」に虞美人と騅が登場する。
- 先生（利用者）から「虞美人のビジュアルがやばすぎる。参考画像を用意して徹底的に絶世の美女にして」「駿馬の騅もビジュアルを用意したい。馬のビジュアルもやばい」と依頼があった。
- 3Dの人物の顔は `tools/build-head-assets.py`（Blender、`source-assets/heads.blend`）で作っているが、元になる頭は男性の写実的な頭（GEO-head_sculpting_realistic）一つだけで、作られているのは張良・劉邦・項羽・范増・項伯・樊噲・項荘・陳平の8人。**虞美人（`gu`）はこの仕組みの外にあり、古い手続き的な頭（`KM_FIGKIT.buildHead`）のまま**なので、骨ばった男性的な顔になっている（頬の張り・広い顎・兜のような髪）。
- 実行時に張良の頭を女性へ変形する案を試したが、眉・生え際・顎に男性らしさが残り不採用にした（main には入れていない）。

## やってほしいこと
### 1. 虞美人（`gu`）の顔と髪
- 女性の元の頭を用意する。Blender Studio の Human Base Meshes（CC0、v1.2.0）の女性の写実的な頭が使えるはず。出典は `docs/assets/manifest.csv` に追記。
- 参考画像を集め（漢代の女性像・俑、漢代の化粧と髪型の資料、現代の歴史考証イラストなど。権利に注意し、リポジトリには入れずにメモで出典を残す）、**誰が見ても美しい若い女性**に仕上げる。
  - 卵形の顔、細い顎、通った小さな鼻、大きめで切れ長の目（二重まぶたは控えめ）、ふっくらした紅の唇、細い弓形の眉（柳眉）、白く透る肌。
  - 漢代の化粧（白粉、頬紅、目元の薄紅、額の花鈿は控えめに）。
  - 髪：高く結った髷（高髻）または垂髻、かんざし・歩揺。今の `cap: 'lady'` の飾りとの干渉を整理する。
- `src/js/koumon-heads.js` の `build()` は `gu` に男性の頭を使わないようにしている（コメントあり）。女性の頭のアセットを `KM_HEAD_ASSETS` に加え、`gu` で使えるようにする。
- 目・まぶた・口（`anchors.mouth`）など既存の頭と同じ取り決めを守る。表情（`smile` など）や話すときの口の動きが破綻しないこと。

### 2. 騅（`makeHorse('zhui')`）と馬全般
- 今の馬（`src/js/koumon-cast3d.js` の `makeHorse` / `makeHorseSDF`）は形が不自然（胴・首・脚の比率、鞍）。
- 参考画像（漢代の馬俑・画像石、現代の馬の解剖図）をもとに、**自然で美しい馬**に作り直す。
  - 騅は「蒼白混じり（葦毛・連銭葦毛）」の駿馬。たてがみと尾、筋肉のついた首と肩、細く締まった脚、蹄。
  - 漢代の鞍・障泥・手綱。
- 既存の動き（騎乗 `ride` で手綱を握る手、`entrance-flow` の「騎乗」テスト、烏江の場面で亭長に騅を譲る場面、間道で走る場面）が壊れないこと。四つの蹄が地面に着くテスト（`tests/character-assets.test.cjs`）も通すこと。

## 制約
- 3Dの読み込みデータが大きい（顔のデータは約30MB、圧縮後約15MB）。**増やす量は最小限に**（低品質LODを用意する、頂点数を抑える）。影絵（2D）は読み込まないので影響なし。
- `npm test` と `npm run test:browser` を通す。`dist/index.html` は `npm run build` で作り直す。`index.html` の該当スクリプトの `?v=` を上げる。
- 史記の本文・書き下し・現代語訳（原文帳）は変えない。
- 変更点は `docs/implementation-audit.md` に日本語で書き足す。
